#  Color Mixer

Color Mixer is a small React project that lets you create different colors by adjusting Red, Green, and Blue (RGB) values.

I built this project to practice React's `useState` hook, handle user input, and understand how to store data in the browser using `localStorage`.

##  Features

*  Adjust Red, Green, and Blue values using sliders.
*  Mix RGB values to create different colors.
*  See the color preview update instantly as you move the sliders.
*  Save your current RGB color combination using `localStorage`.
* Explore different color combinations with a simple interface.

##  Built With

* **React.js** – For building the user interface.
* **JavaScript** – For application logic and event handling.
* **HTML5** – For structuring the interface.
* **CSS3** – For styling.
* **Local Storage** – For saving the selected RGB values in the browser.


## What I Learned

While building this project, I practiced:

* Managing component state using React's `useState` hook.
* Handling slider input with the `onChange` event.
* Updating CSS styles dynamically using RGB values.
* Saving data in the browser with `localStorage`.
* Using `JSON.stringify()` to store an object as a string.
